# 架构与路由

## 核心模式

- 页面装配层：读取页面配置并按顺序渲染区块。
- 区块组件层：每个区块变体都是独立模块。
- 变体注册表：统一维护 `kind + variant -> component` 映射。

## 路由规则

- 路由按用户意图推断，不强制固定完整路由集合。
- 必备页面：
  - 首页（必须包含可提交留资的表单区块）
  - 联系页（必须可留资）
  - 隐私页
- 当产品条目 >= 2 时，启用 `/products/[slug]`。

## 扩展规则

新增首页结构时：

1. 新增区块变体组件。
2. 在注册表注册新变体。
3. 在页面配置中选择该变体。
4. 避免在路由文件内硬编码大段内容。
