# SEO 与追踪

## SEO 基线

- 每个页面都要有 title / description / keywords。
- 必须包含 canonical + hreflang（zh/en）。
- sitemap 与 robots 要和有效页面同步。

## 结构化数据

- 首页：Organization + WebSite
- FAQ 页：FAQPage
- 产品详情页：Product

## 追踪基线

- GTM 作为唯一标签入口。
- Cookie 同意前禁止营销追踪。
- 必备事件：
  - `page_view`
  - `cta_click`
  - `form_submit`
  - `whatsapp_click`
  - `email_click`
  - `phone_click`
